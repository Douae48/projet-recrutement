# Job Matcher - Mobile App (React Native)

## 📝 Description
Job Matcher est une application mobile cross-platform développée avec **React Native** et **Expo**. Ce projet valide les compétences en développement mobile, gestion d'état global et consommation d'API REST.

## 🚀 Objectifs Mobile
- Interface réactive (Native Performance).
- Navigation fluide (Stack & Tab Navigators).
- Sécurité JWT et persistance AsyncStorage.
- Moteur de recommandation basé sur Neo4j.

## 🛠️ Stack Technique
- **Mobile :** React Native, Expo, Axios, React Navigation, Context API.
- **Backend :** Node.js, Express.js, Neo4j AuraDB (Cloud), JWT, Bcrypt.
